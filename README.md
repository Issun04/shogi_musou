# shogi_musou / 将棋無双
「王将」を操作して攻め寄せる「と金」を倒そう！

## Features / 主な機能
Shift：攻撃
Enter：ボム
TAB：ガード
方向キー：移動

## How to / 攻略法
アイテムは３種類、時間によって出現します。すでに出現しているアイテムを取らないと、次のアイテムは出ません。
右上のゲージは上が体力ゲージ、下がガードゲージです。ガードゲージは、ガードをしていない時間に少しずつ回復します。
と金に最下段を突破されてもダメージになります。

## Requirements / 動作環境
HTMLブラウザで動作します。
