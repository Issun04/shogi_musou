# shogi_musou / 将棋無双

「王将」を操作して攻め寄せる「と金」を倒そう！

## Features / 主な機能

Shift：攻撃<br>
Enter：ボム<br>
TAB：ガード<br>
方向キー：移動<br>

## How to / 攻略法

アイテムは３種類、時間によって出現します。すでに出現しているアイテムを取らないと、次のアイテムは出ません。<br>
右上のゲージは上が体力ゲージ、下がガードゲージです。ガードゲージは、ガードをしていない時間に少しずつ回復します。<br>
と金に最下段を突破されてもダメージになります。<br>

## Requirements / 動作環境

HTMLブラウザで動作します。
